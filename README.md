## 大带宽VPS的三个判断标准

**端口是独享还是共享，看加购项就知道。** JustHost 把 Special 系列的端口写成 fair-share，意思是这 300Mbps 不是拉给你一根专用管道，而是同一节点上的用户按公平原则分摊。官网附加服务里有一行“独享 1Gbps 带宽 ¥2240.85/月”，这个价格差说明默认套餐买到的是共享端口。共享端口平时够用，但邻居持续跑大流量时，你的实际吞吐会掉。

**流量额度和带宽数字要分开算。** 100Mbps 满载一小时约 45GB，跑满 1TB 只要 22 小时左右。JustHost 的 Special 系列标的是不限流量，300Mbps 理论上一个月能跑 93TB，但这个数字只有在持续满载时才成立，而 fair-share 机制本身不允许你长期占满。真要按 300Mbps 不间断跑一个月，隔壁用户会先受影响，机房也会介入。所以“不限流量”给你的是不担心超额账单，不是保证时刻满速。

**端口速率要和 CPU、内存匹配。** 1 核 1GB 配 300Mbps，高并发时先撑不住的往往是 CPU，HTTPS 握手和 PHP 查询会把核心吃满，端口再宽也发不出去。Sirius 这种配置适合单进程、低并发的传输类业务，不适合同时跑 Web、数据库和下载。

## 常见问题

**300Mbps 是独享的吗？**
不是。官网标注为 fair-share，同节点用户分摊。需要独享端口要单独加购，1Gbps 独享标价 ¥2240.85/月。

**流量真的不限吗？**
套餐不设月度流量上限，官网写明“免费不限流量”。但端口是公平共享，持续满载会影响同节点其他用户，实际可用带宽不是恒定 300Mbps。

**续费会涨价吗？**
官网当前展示的折后价对应预付 12 个月。续费价格未在公开页面单独列出，下单前在订单页确认。

**能退款吗？**
公开页面没有统一的退款条款，下单前通过工单或订单页确认，年付尤其要问。

**可以换机房或换 IP 吗？**
可以，官网写明支持在用户中心即时切换机房、随时更换 IP 地址。

**有自动备份吗？**
没有。需要自己搭建备份方案。

**支持哪些付款方式？**
官网下单流程走在线支付，具体可用渠道在结账页显示。中文站以人民币计价，英文站以美元计价。
